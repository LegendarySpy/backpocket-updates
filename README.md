# Backpocket

Backpocket is a tiny macOS menu bar app for the bits of text you type all the
time. Double-tap a modifier key, find what you need, and press Return to insert
it into the text field you are already using.

**[Download Backpocket for Mac](https://github.com/LegendarySpy/backpocket-updates/releases/latest/download/Backpocket.dmg)**

Requires macOS 26 Tahoe or later.

## What it does

- Opens beside your cursor with a double-tap of Option, Control, Command, or Shift
- Finds saved facts by name or value, with field-aware suggestions
- Supports dates, clipboard contents, UUIDs, app names, and other placeholders
- Keeps locked facts encrypted and types them without putting them on the clipboard
- Can sync saved facts between your Macs with iCloud
- Runs locally with no analytics, ads, or automatic crash reporting

You can save up to five facts for free. Backpocket Unlimited is a $5 one-time
purchase and supports up to three active Macs.

## Install

1. Download and open `Backpocket.dmg`.
2. Drag Backpocket into Applications.
3. Open Backpocket and follow the short setup.

Backpocket asks for Accessibility access so it can find the focused text field
and insert the fact you choose. It does not upload your facts or focused-field
content.

Backpocket checks for new releases automatically, or you can check manually from
the About tab.
