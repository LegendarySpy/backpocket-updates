# Backpocket updates (retired)

Backpocket moved to one repository: **[LegendarySpy/backpocket](https://github.com/LegendarySpy/backpocket)**. Downloads, releases, the changelog, and the update feed all live there now.

This repo only keeps `appcast.xml` around for installs of 1.0.3 and older, which still check this address. The main repo mirrors each new appcast here, so those installs update onto the new feed. Once nobody is left on 1.0.3, this repo gets archived.
